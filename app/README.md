# 🐍 Sarpa – Sri Lankan Snake Identifier App

![Sarpa App Screenshot](../images/app.jpeg) 

**Sarpa** is a mobile app that helps users identify snakes in Sri Lanka using an image. It provides possible species, prevention tips, and first aid info — all in one place.

---

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS)
- Expo CLI installed globally:  
```bash
  npm install -g expo-cli

  cd Sarpa

  npm install

  expo start
